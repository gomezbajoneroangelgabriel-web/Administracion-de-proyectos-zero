Nombre del proyecto
Página web "Escuadrón 85 (swoordmen)"
Descripción
La academia de vuelo virtual conocida como "Escuadrón 85", especializada en cursos de aviación virtual en el simulador Digital Combat Simulator (DCS), solicita la creación de una página web para realizar un mejor seguimiento y control de los alumnos.
El proyecto busca proporcionar una plataforma que permita gestionar de manera más eficiente la información relacionada con los alumnos, cursos y actividades de la academia, tomando como referencia el nivel parcial/completo de IVAO, otra academia de vuelo especializada en Microsoft Flight Simulator (MSFS) 2020-2024.

Nuestro primer paso
Se entablarán reuniones para realizar las planeaciones correspondientes al desarrollo de la página web. Durante estas reuniones se conversará sobre las funcionalidades, diseño y estructura de la página, así como sobre los recursos con los que cuenta la organización, con el objetivo de adaptar y negociar los términos del proyecto.
Los términos abarcarán aspectos como:
Tiempos de entrega.
Pagos.
Componentes y recursos del servidor.
Funcionalidades de la página.
Recursos disponibles.
Requerimientos técnicos.
Nombre clave del proyecto

El nombre clave del proyecto será referido como "Zero".
